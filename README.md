### 先从一个作品开始

#### [瑶叶·圆珠笔视频 Skill](https://github.com/yaoyepro/yaoye-ballpen-video)

给 AI 一个主题、一段文字、一首诗或一首歌，让蓝色圆珠笔在横线笔记本上写字、画涂鸦，把内容变成手绘风格视频。
